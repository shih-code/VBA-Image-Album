# 使用說明（影像自動化歸檔系統）

一個 Excel 小工具，幫你整理一整批照片：自動去掉重複的、找回不小心不見的、排版成好瀏覽的畫面，還能一鍵輸出成 PDF。不用另外裝軟體，也不用看得懂程式碼。

---

## 🔴 開始使用前，請先記住這兩件事

**1. Excel 裡的圖片只是副本。先確認畫質沒問題，再考慮刪掉原始圖片；重要的圖片，建議乾脆不要刪。**

**2. 一個專案的圖片數量，建議不要超過 500～1000 張。超過的話，開一個新專案來處理。**

---

## 需要準備什麼

- Windows 電腦
- 有安裝 Microsoft Excel

## 取得與開啟

有兩種方式，選一種就好：

**方式一（推薦）**：直接下載本專案的 `.xlsm` 檔案，裡面已經做好完整的操作介面，不用碰任何程式碼。下載完照下面「下載後的必要步驟」做就能用。

**方式二（適合想自己動手的人）**：自己建一個空白活頁簿，把本專案的原始碼（`.bas`／`.cls` 檔案）匯入進去。步驟見下方「第一次使用前的準備」。

不管選哪一種，**下載完都要先做完下面這件事，才能正常使用**。

### 下載後的必要步驟：解除封鎖

Windows 會把從網路下載的檔案自動標記為「來自網際網路」，這個標記會讓 Excel 用更嚴格的方式對待這個檔案——**有些情況下，連平常那條「啟用內容」的黃色警告列都不會正常出現，巨集直接被完全擋死，怎麼點都沒用**。所以下載完，開啟檔案之前，先做這一步：

1. 在檔案總管裡找到你剛下載的檔案，**滑鼠右鍵點擊**它，選擇「內容」（Properties）。
2. 在跳出的視窗最下面，如果看到一行寫著「**這個檔案來自另一部電腦，可能已封鎖以協助保護這部電腦**」，旁邊會有一個「**解除封鎖**」（Unblock）的勾選框，把它**打勾**。
3. 按「確定」關閉視窗。

這樣就完成了，之後才用 Excel 打開這個檔案。

### 開啟檔案時記得啟用巨集

做完「解除封鎖」之後，打開檔案，Excel 上方通常會出現黃色警告列，寫著「已停用巨集」或「安全性警告」，這時記得點選**「啟用內容」**或**「啟用巨集」**，不啟用的話按鈕會沒有反應。

## 第一次使用前的準備（只需要做一次，方式二才需要看這段）

這個工具是用一份一份程式碼檔案的形式提供的，你需要先建立一個空白的 Excel 檔案，把程式碼放進去，執行一次之後，操作介面才會自動生成。步驟不長，照著做就好。

### 1. 建立一個新的巨集啟用活頁簿

打開 Excel，建立一個新的空白活頁簿，另存新檔時，「存檔類型」選擇 **「Excel 啟用巨集的活頁簿 (*.xlsm)」**，取個檔名存起來。

### 2. 開啟 VBA 編輯器

按鍵盤上的 `Alt` + `F11`，會跳出一個新視窗，這就是 VBA 編輯器。

### 3. 啟用必要的元件

在 VBA 編輯器上方選單點 `工具` → `設定引用項目`，在跳出的清單裡找到 **Microsoft Scripting Runtime**，把前面的方框打勾，按「確定」。

### 4. 把程式碼檔案匯入進來

1. 到你下載的這個專案裡，找到裝著 `.bas`／`.cls` 檔案的資料夾。
2. 回到 VBA 編輯器，左側會有一個「專案總管」視窗，裡面看得到你剛剛存的活頁簿名稱。滑鼠對著它**點一下滑鼠右鍵** → 選 `匯入檔案`。
3. 在跳出的視窗裡，把資料夾裡的檔案**全部選起來**（可以先點第一個檔案，按住鍵盤 `Shift` 再點最後一個檔案，一次全選），按「開啟」。
   - 如果你的 Excel 版本這個視窗不能一次選多個檔案，就重複「右鍵 → 匯入檔案」這個動作，一次匯入一個檔案，效果一樣。
4. 匯入完成後，左側「專案總管」裡應該會出現一長串檔案名稱（例如 `Mod_Main`、`cls_Config` 等等），代表匯入成功。

### 5. 第一次執行，生成操作介面與資料夾結構

1. 關掉 VBA 編輯器視窗，回到 Excel 畫面。
2. 按鍵盤上的 `Alt` + `F8`，會跳出一個巨集清單視窗。
3. 清單裡找到 **`主動初始化`**，點選它，按「執行」。
4. 稍等一下，系統會自動建立好操作介面跟所需的資料夾結構，這樣就完成了。

之後每次打開這個檔案，直接就能看到操作介面，不需要再重複以上步驟。如果操作介面不見或跑版了，隨時可以再執行一次 `主動重繪UI` 把它恢復原狀，不會弄壞你已經匯入或處理過的照片資料。

## 認識操作介面

打開檔案後，你會看到一個「操作介面」分頁，上面有幾個輸入格跟一排按鈕：

| 按鈕 | 做什麼 |
|---|---|
| **開始作業** | 匯入新照片，點下去會跳出視窗讓你選檔案或資料夾 |
| **全面排版** | 主要引擎：去重、找回遺失的圖片、重新排版，一次做完 |
| **匯出圖片 PDF／橫式目錄 PDF／附件目錄 PDF** | 把整理好的照片或附件輸出成 PDF |
| **局部重排** | 開啟後，之後排版只重排新增或有異動的照片，分頁多的時候速度快很多 |
| **自動排版開關** | 開啟後，你在介面上改寬度、間距，系統會立刻自動重排一次 |
| **操作台鎖定／目錄鎖定／工作表鎖定** | 各自把對應的表鎖起來，避免不小心改到 |
| **系統日誌** | 點一下看這個工具做過什麼事、有沒有失敗；再點一下收起來 |
| **格式化** | 清空目前的畫面重新開始，會先問你要不要保留原本的照片備份 |

寬度、間距、命名規則這些輸入格，滑鼠停在上面通常會有提示文字。不確定要填什麼，就先用預設值。

## 基本使用流程

### 步驟一：匯入照片

點**「開始作業」**，選你要匯入的照片或資料夾。系統會自動複製一份到它自己管理的「圖片整理夾」，開始處理——你原本的照片不會被動到（見下方「資料夾說明」）。

你也可以不點「開始作業」，直接把照片拖進「圖片整理夾」，一樣會被正確處理，接著做下一步就好。

### 步驟二：執行全面排版

點**「全面排版」**。這一步系統會自動：

- 檢查有沒有重複的照片
- 檢查有沒有照片不小心不見了，需要救回來
- 把所有照片依目前設定重新排版

跑的過程中，如果系統需要你確認什麼（例如兩張照片同名、要不要救援），會跳出視窗問你。不確定選哪個的話，選**比較保守、不會刪東西或蓋掉東西**的那個選項。

### 步驟三：需要的話，匯出成果

想把整理好的照片輸出成 PDF 帶走或分享，點操作介面上對應的匯出按鈕就好。匯出好的檔案會放在系統自動建的「匯出」資料夾裡。

## 資料夾說明：哪些可以動、哪些不要碰

用過幾次之後，Excel 檔案旁邊會自動長出幾個資料夾。搞清楚它們是做什麼的，才不會不小心弄丟東西：

| 資料夾 | 這是什麼 | 可以動嗎 |
|---|---|---|
| 圖片整理夾 | 系統實際存放照片的地方 | **不要手動刪除或改檔名**，都透過系統按鈕操作 |
| 附件目錄 | 存放非圖片附件的地方 | 同上，透過系統按鈕操作 |
| 匯出 | PDF 匯出的成果 | 可以自由搬走，這是給你帶走的東西 |
| 封存備份 | 備份跟日誌的存放處 | 除非你確定不需要，建議先留著 |
| 隔離與雜物清單 | 系統覺得有問題、先放旁邊觀察的檔案 | 先查清楚為什麼會在這裡，再決定要不要處理 |
| 圖片母夾根目錄（不是整理夾） | 你自己放照片的地方 | 系統不會主動處理這裡的檔案 |

**這個工具從頭到尾只會「複製」你的照片，不會「搬走」或「刪除」它們。**

## 緊急工具（`Alt+F8` 巨集清單）

操作介面或系統說明書意外不見時，按鈕會因為找不到介面而失靈。這時按 `Alt+F11` 開啟 VBE，再按 `Alt+F8` 開啟巨集清單，執行對應的工具：

| 工具名稱 | 什麼時候用 |
|---|---|
| **主動初始化** | 操作介面連同資料夾結構都不見了，重建全部 |
| **主動重繪UI** | 只是操作介面跑版或消失，資料夾都還在，只重建介面 |
| **強制統一密碼** | 改了系統密碼之後，把所有表的鎖統一改成新密碼 |
| **封存並清除系統日誌** | 手動把系統日誌整理一次，不用等系統自動觸發 |

這幾個工具永遠都在 `Alt+F8` 清單裡找得到。

### ⚠️ 操作介面那張表如果被整張刪掉，重建不會自動救回一個功能

如果「操作介面」那張表**整張被刪掉**（不是版面亂掉，是整張表不見了），執行`主動初始化`或`主動重繪UI`確實能把畫面、按鈕、資料夾都變回來——**但這是一張全新的表，不是原本那張**。原本那張表上，有一段負責「你改設定時系統要不要自動反應」的程式碼，這段程式碼**不會**跟著自動回來。表面上看起來一切正常，其實這個功能已經失效了，而且不會有任何警告告訴你。

**遇到這種情況該怎麼辦**：重建完成後，按 `Alt+F11` 打開 VBE，找到「操作介面」那張表，把它的程式碼整段貼回去（可以從本專案 repo 的原始碼拿，或問我）。如果只是版面亂掉、按鈕不見，但表本身還在，直接重建就好，不用做這一步。
