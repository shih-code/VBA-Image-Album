## 一、Schema（資料合約）：《圖片目錄》工作表欄位結構

全系統身分判斷的核心資料結構。任何模組讀寫此結構，欄位語意與順序不得自行調整。

| 欄位 | 名稱 | 用途 | 是否參與身分判斷 |
|---|---|---|---|
| A (1) | 識別名稱 | 旗幟命名格式，Shape 名稱與實體檔名的唯一鍵 | 是（間接，透過雜湊反查） |
| B (2) | 目前HASH | 這筆紀錄目前對應實體的內容雜湊，每次身分轉移（救援/取代/正名）都會被覆寫 | 是，核心判斷依據 |
| C (3) | 目前物理路徑 | 指向整理夾內的實體檔案位置 | 否 |
| D (4) | 檔案大小 | | 否 |
| E (5) | 登錄時間 | | 否 |
| F (6) | 檔案修改時間 | | 否 |
| G (7) | 管線執行狀態 | 例如「已歸位」「系統救援」 | 否 |
| H (8) | 是否觸發救援 | 「是」代表 isBounty，處於等待救援中狀態 | 是，決定該筆是否進入候選比對名單 |
| I (9) | 原始HASH | 血統錨點，第一次登記後永久不變，唯一例外是使用者明確選擇「取代舊血統」 | 是，核心判斷依據 |
| J (10) | 實體狀態 | 例如「檔案正常」 | 否 |
| K (11) | 顯示名稱 | `StripHashSuffix` 計算得出，純顯示用途 | 否，禁止參與任何比對 |

> 第2欄與第9欄分工原則、旗幟命名格式等延伸規則，唯一事實來源見
> `影像整理檔_V2_規格書.md` 第三部分，本表僅收錄欄位結構本身。

### 7.7 底層基礎物件

**`cls_Config.cls`** — 全系統唯讀組態 SSOT，全數 `Property Get`，嚴禁 `Let`/`Set`。
完整屬性清單依語意分為六組：

| 分組 | 代表屬性 | 說明 |
|---|---|---|
| 系統名稱與工作表 | `SheetName*`、`SheetSys*`、`PrefixCustom`、`PrefixOldCatalog` | 見第二節 Database |
| UI 門面／字體 | `AppTitle*`、`FontMain`、`FontSize*` | 介面顯示文字與字型 |
| 下拉選單選項 | `Opt*` | 見第五節 Enum |
| 色彩與版面幾何 | `Theme*`、`Drawer*`、`Color*`、`GapX`/`GapY`、`QuarterW` | 莫蘭迪色系與排版幾何常數 |
| 固定儲存格／按鈕 | `Cell*`、`Btn*`、`RangeSettingsConsole` | 見第三節 DOM ID 等效物 |
| 資料夾路徑 | `IO*`（`IOOrganizeFolder`、`IORescueFolder`、`IOAttachment*`、`IOBackupSnapshotFolder`、`IOLogArchiveFolder` 等共約 25 項） | 硬碟拓樸，唯一事實來源，詳見規格書第二部分 |
| 安全與數值邊界 | `SecurityPassword`、`MaxSafetyPoint`、`RescueEmbedWidth/Gap`、`Min/MaxImgWidth`、`Min/MaxImgSpacing`、`MinFreeDiskSpaceGB`、`MinAvailableMemoryMB`、`HugeFileLimit` | P0 安全相關數值上下限 |
| PDF 匯出版面 | `PDF*`（`PDFGridLayout`、`PDFMarginCM`、`PDFNumCols` 等共約 15 項） | PDF 宮格算繪參數 |
| 使用者可擴充清單 | `CopySuffixPatterns`（V2.3.1新增，見ADR V2-102） | 陣列型常數，供使用者依實際遇到的複製檔名樣式自行增補，不需改動任何判斷邏輯 |

> 屬性總數約 140 項，逐條列出對本文件可讀性幫助有限；完整清單以
> `cls_Config.cls` 原始碼為準（本檔案不重複抄錄每一行，避免產生第二個
> 需要手動同步的落點，違反 SSOT）。**若要新增/刪除任一屬性，仍必須視為
> Contract 異動，比照本章其他項目走 Registry 更新流程。**
